# Data format

No real subject data are included. Input is preprocessed time-by-AAL90 text/CSV/TSV.
Graph .pt files generated by scripts/01_build_hypergraphs.py contain:

- schema: shnd-paper-v1
- construction: permutation count, alpha, seed, target_time, std convention
- x_derivative: [ROI, time] normalized derivatives WITHOUT derivative centering
- x_raw_zscore: optional raw signal feature baseline
- edge_list: significant pairs/triples only; no completion or cap
- edge_p_values: empirical p values
- edge_w: signed cofluctuation sequence, one row per retained edge
- edge_strength: mean absolute edge_w
- label, dataset, group, subject_id
